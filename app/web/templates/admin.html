提取码 / 包裹管理

IP 封禁

发现恶意/危险文件后，在包裹上点「封禁 IP」，或在此手动添加。被封 IP 无法再上传。

举报处理

用户从提取页举报的分享。处理 = 删除包裹及云盘文件 + 拉黑文件 SHA-256（同内容永久无法再传）+ 封上传者 IP。

文件 SHA-256 黑名单

黑名单中的文件内容（按 SHA-256 识别，改名无效）无法再上传。处理举报时自动添加，也可手动添加（可从包裹详情或下载文件计算获得）。

AI 内容审核（普通大模型）

用 OpenAI 兼容大模型审核文件名/标题（全量）与 ≤上限 的小文件内容（文本类提文本、图片类多模态）。宽松判断、AI 故障自动放行；拒绝不自动拉黑 SHA（防误判），记录留查。大文件内容不过服务器（直传架构），靠黑名单+举报兜底。

上传与存储设置

移动云盘绑定

长期推荐（对齐 OpenList）：填 邮箱 Cookie + 用户名 + 密码，Authorization 可留空——系统会自动登录并续期。
邮箱 Cookie 来自 https://mail.10086.cn/（Cookie 头字符串，需含 Os_SSo_Sid / RMKEY）。
也可只填 Authorization（yun.139.com → hcy/file/list → Basic 后内容），过期需手更。

OpenList 存储

用 OpenList（AList 的活跃分支）做存储层：先在 OpenList 里把网盘挂载好，这里只填 OpenList 地址与账号即可。
文件按 根目录/年/月/ 存放，缺失目录会自动创建；「直链下载」开启时浏览器 302 到 /d/…?sign=…，不占服务器带宽（要求浏览器能访问该地址）。

WebDAV 存储

通用 WebDAV：Alist / 坚果云 / Nextcloud / 群晖 / 飞牛自建等。选为上方「存储后端」后生效。
文件按 根目录/年/月/ 存放；下载经服务器中转（WebDAV 需要 Basic 认证，不能直接暴露直链）。

本地存储

文件直接写入服务器磁盘（NAS 本机盘 / 挂载目录），适合内网或无云盘场景。选为上方「存储后端」后生效。
下载经服务端流式转发，支持 Range；Docker 部署时请把宿主机目录挂载到容器内路径。

管理员账号

修改用户名/密码后立即生效；密码留空表示不修改。
